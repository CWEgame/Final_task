# Our final assignment / My English Class Website 
These websites showcase my experience in English class. I have split them into three separate sites, each presenting a different part of my English class. I have included pictures to show that the websites work both on a pc and phone format. 

## Introduction 
This page presents my English experience in the course English 6, which runs from 2025-08-14 to 2026-06-04. It includes a short introduction about the course and an image related to the start of the class. At the bottom of the page there is a quiz section where visitors can test how much they remember after reading the other pages.

## My quiz 
This page contains a quiz based on my English class. It includes three questions where the user can type answers about my teacher’s last name, the end date of the course, and a character from a book I am reading. Each question has its own input field, submit button, and result message that shows whether the answer is correct or wrong.
